# 🌐 Chapter 09 – Subnetting

## 📖 Overview

Subnetting is the process of dividing a large IP network into smaller, manageable subnetworks (subnets). It improves network efficiency, enhances security, reduces broadcast traffic, and optimizes IP address utilization.

Subnetting is a fundamental networking skill used by Network Engineers, Linux Administrators, Cloud Engineers, DevOps Engineers, and Site Reliability Engineers (SREs). It plays a critical role in designing scalable and secure infrastructures in AWS, Azure, Google Cloud, Docker, and Kubernetes environments.

This chapter covers subnet masks, CIDR notation, network IDs, host IDs, subnet calculations, VLSM, FLSM, and real-world subnetting examples.
