# Switching Interview Questions

## 1. What is switching?

Switching is the process of forwarding network frames between devices using MAC addresses.

## 2. What is a switch?

A switch is a Layer 2 networking device that forwards frames based on MAC addresses.

## 3. What is a MAC address table?

A MAC address table maps MAC addresses to switch ports so frames can be forwarded efficiently.

## 4. What is a Linux bridge?

A Linux bridge is a software-based Layer 2 switch that connects network interfaces.

## 5. What is the difference between a switch and a router?

A switch primarily forwards frames using MAC addresses, while a router forwards packets between networks using IP addresses.

## 6. Why are bridges used in Docker?

Docker uses Linux bridges to provide Layer 2 connectivity between containers and the host networking stack.
