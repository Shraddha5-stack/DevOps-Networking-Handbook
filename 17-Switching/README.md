# 17 - Switching

## 🎯 Overview

Switching is the process of forwarding network frames between devices using MAC addresses.

## 📚 Topics

- Layer 2 Switching
- MAC Addresses
- MAC Address Table
- Linux Bridges
- Forwarding Database (FDB)
- Docker Bridge Networking

## 🧪 Practical

The practical lab uses Linux networking commands to inspect:

- Network interfaces
- Linux bridges
- MAC addresses
- Forwarding database (FDB)
- Neighbor information
- Docker bridge networking

## 💡 Key Learning

A switch operates mainly at **Layer 2 (Data Link Layer)** and uses **MAC addresses** to forward Ethernet frames to the correct destination.

In Linux, a **bridge** performs a similar Layer 2 forwarding function and is commonly used in Docker networking.
