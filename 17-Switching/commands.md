# Switching Commands Cheat Sheet

| Command | Purpose |
|---|---|
| `ip link show` | Show network interfaces |
| `ip -br link` | Show interfaces in brief format |
| `bridge link` | Show bridge interfaces and ports |
| `bridge fdb show` | Show forwarding database entries |
| `ip neigh` | Show neighbor/ARP information |
| `ip addr show` | Show IP addresses |
| `ip route` | Show routing table |
