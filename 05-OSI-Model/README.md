# 📖 Overview

The OSI (Open Systems Interconnection) Model is a conceptual framework that explains how data moves between devices over a network.

It divides network communication into **7 different layers**, where each layer performs a specific function.

Understanding the OSI Model helps DevOps engineers:

- Troubleshoot network issues.
- Understand protocols.
- Debug application connectivity problems.
- Design better infrastructure.

# 🌍 Why Learn OSI Model?

The OSI Model provides a structured way to understand networking.

Example:

When you open a website:

```
Application Layer
        ↓
Presentation Layer
        ↓
Session Layer
        ↓
Transport Layer
        ↓
Network Layer
        ↓
Data Link Layer
        ↓
Physical Layer
```

Data travels through all layers before reaching the destination.

# 🔑 Key Takeaways

- OSI Model has 7 layers.
- Each layer performs a specific function.
- Lower layers handle data transmission.
- Upper layers handle application communication.
- OSI helps troubleshoot networking problems systematically.
