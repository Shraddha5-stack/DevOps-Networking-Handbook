# 📘 Chapter 3 – Network Topologies

## 📖 Overview

This chapter explains how devices are physically or logically connected in a computer network. You'll learn different network topologies, their advantages, disadvantages, real-world applications, and how they are used in modern IT and DevOps environments.

---

## 🎯 Learning Objectives

After completing this chapter, you will be able to:

- Understand what a network topology is.
- Differentiate between physical and logical topologies.
- Explain Bus, Star, Ring, Mesh, Tree, and Hybrid topologies.
- Compare the advantages and disadvantages of each topology.
- Identify real-world use cases.
- Prepare for networking and DevOps interviews.
