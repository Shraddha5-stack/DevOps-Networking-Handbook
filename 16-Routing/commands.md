# Routing Commands Cheat Sheet

| Command | Purpose |
|---|---|
| `ip route` | Show routing table |
| `ip route show` | Show routes |
| `ip route show default` | Show default route |
| `ip route get 8.8.8.8` | Determine route to destination |
| `ip rule` | Show routing rules |
| `ip neigh` | Show neighbor/ARP information |
| `ping -c 4 192.168.1.1` | Test gateway |
| `ping -c 4 8.8.8.8` | Test connectivity |
| `traceroute 8.8.8.8` | Trace packet path |
| `sudo ip route add ...` | Add a route |
| `sudo ip route del ...` | Delete a route |
