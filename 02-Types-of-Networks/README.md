# 📘 Chapter 2 – Types of Networks

Welcome to **Chapter 2** of the **DevOps Networking Handbook**.

In this chapter, you will learn about the different types of computer networks, their characteristics, advantages, disadvantages, and real-world applications. Understanding these network types is essential for building a strong foundation in networking and DevOps.

---

# 📖 Overview

Computer networks are classified based on their geographical coverage, size, ownership, and purpose.

Different network types are designed to solve different communication problems. For example, a home network requires a Local Area Network (LAN), while the Internet itself is the largest example of a Wide Area Network (WAN).

This chapter explains the most commonly used network types and how they are used in modern IT infrastructure and DevOps environments.
