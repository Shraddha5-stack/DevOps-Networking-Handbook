# 🌐 Chapter 08 – IP Addressing

## 📖 Overview

An IP (Internet Protocol) address is a unique identifier assigned to every device connected to a network. It enables devices to communicate with each other by identifying the source and destination of network packets.

IP addressing is one of the most fundamental concepts in computer networking. Whether you are configuring Linux servers, deploying applications on AWS, managing Docker containers, or troubleshooting Kubernetes clusters, understanding IP addresses is essential.

This chapter covers IPv4 and IPv6 addressing, public and private IPs, static and dynamic addressing, CIDR notation, network and host IDs, and common Linux commands used to inspect and troubleshoot IP configurations.
